Local widget test page

This page loads the chatbot widget from your deployed Render backend and points it at a real site to answer questions about.

How it works locally: when a page is opened from your computer the browser's domain is localhost / a file path, which is not a real site to crawl. The data-domain attribute below overrides that and tells the widget which real site to answer about. Change it to whatever site you want to test. Remove the attribute entirely when you embed on the actual website.

Click the chat bubble in the bottom-right corner to start.
